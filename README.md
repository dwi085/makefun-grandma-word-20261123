An entry for the [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) bounty on make.fun.

`main.ts` writes exactly one word to `/output/entry.txt`: the single word Grandma would text about AI — **contraption**, the old-fashioned word she would use for any newfangled machine. Warm, a little baffled, and one word. Deterministic: every run writes the same bytes.
